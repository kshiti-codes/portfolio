01

Core Building Blocks

@Module()

Module

Root unit of organization. Every NestJS app has at least one — the AppModule. Declares controllers, providers, imports, and exports.

Think of it as a feature folder — groups related things (controllers + services + providers) into a cohesive unit.
@Controller()

Controller

Handles incoming HTTP requests and returns responses. Defines routes using decorators like @Get(), @Post(). Does NOT contain business logic.

@Get @Post @Put @Delete @Patch
@Injectable()

Provider / Service

Any class decorated with @Injectable(). Services hold business logic. Providers can be services, repositories, factories, helpers, etc.

Controllers ask "what?" — Services decide "how?"
@UseGuards()

Guard

Determines whether a request should proceed. Used for authentication & authorization. Returns true to allow, false to block. Runs AFTER middleware, BEFORE interceptors.

@UseInterceptors()

Interceptor

Wraps around route handler execution. Can transform request/response, add extra logic, or handle errors. Runs BEFORE and AFTER the handler (like a sandwich).

Use for: logging, caching, response mapping, timing.
Middleware

Middleware

Runs BEFORE the route handler. Has access to req, res, and next(). Similar to Express middleware. Used for logging, CORS, body parsing.

@UsePipes()

Pipe

Transforms and validates input data before it reaches the controller handler. Two uses: transformation (string → number) and validation (throw if invalid).

ParseIntPipe ValidationPipe ParseUUIDPipe
@UseFilters()

Exception Filter

Catches exceptions thrown anywhere in the application and formats the error response. Default: HttpExceptionFilter. You can create custom ones.

Decorator

Decorator

TypeScript metadata annotations that define behavior. NestJS is built on them: @Module, @Controller, @Get, @Body, etc. You can create custom decorators.

IoC Container manages all instances
NestJS IoC Container
injects into ↓
@Injectable() Service

Business logic — injected into controllers or other services

@Controller()

Receives services via constructor injection automatically

Custom Providers

useClass / useValue / useFactory / useExisting

// 1. Mark as injectable
@Injectable()
class OrderService {
createOrder() { /* ... */ }
}

// 2. Constructor injection — NestJS resolves automatically
@Controller('orders')
class OrderController {
constructor(private readonly orderService: OrderService) {}

@Post()
create() { return this.orderService.createOrder(); }
}
Scope: DEFAULT

Singleton Scope

One instance shared across the entire app. Created once, reused everywhere. Most performant — this is the default.

Scope: REQUEST

Request Scope

New instance created for each incoming request. Useful when you need request-specific data (e.g., current user). Has performance overhead.

Scope: TRANSIENT

Transient Scope

New instance created for each consumer that injects it. Not shared at all.

Token Type Syntax When to use

String Token provide: 'CONFIG' Non-class values (strings, objects)

useClass useClass: MockService Swap implementation (e.g., testing)
useValue useValue: { apiUrl: '...' } Static values, config objects
useFactory useFactory: (dep) => new X(dep) Dynamic/async instantiation
useExisting useExisting: OrderService Alias — reuse existing provider
04

Module System

@Module({
  imports:  [DatabaseModule, AuthModule],   // bring in other modules
  controllers: [OrderController],           // handle routes
  providers:  [OrderService, OrderRepo],    // business logic & data
  exports:    [OrderService],                // share with other modules
})
export class OrderModule {}
Root Module

AppModule

Entry point. Bootstrapped by NestFactory.create(AppModule). Imports all feature modules.

Feature Module

Domain Module

Groups related features. E.g., OrderModule, UserModule, PaymentModule. Keeps codebase modular and scalable.

Shared Module

Shared Module

Exports reusable providers. Any module that imports a SharedModule gets access to its exported providers.

@Global()

Global Module

Providers available everywhere without importing. Use sparingly — only for truly global things like config or logger.

Dynamic Module

forRoot() / forFeature()

Module configured at runtime. forRoot(options) configures once at app root. forFeature(entity) configures per feature (e.g., TypeORM).

DTOs & Validation

class-validator decorators

  • @IsString() — must be string
  • @IsEmail() — valid email format
  • @IsNotEmpty() — not null/undefined/empty
  • @IsNumber() — numeric value
  • @IsUUID() — valid UUID
  • @IsEnum(Status) — enum value
  • @MinLength(n) / @MaxLength(n)
  • @IsOptional() — skip if absent
  • @IsArray() / @ArrayMinSize(n)
  • @ValidateNested() — nested object

class-transformer decorators

  • @Transform() — custom transformation
  • @Exclude() — omit from output
  • @Expose() — include in output
  • @Type() — specify nested type
  • plainToInstance() — convert plain object
  • instanceToPlain() — serialize class
  • @SerializeOptions() — override serialization
// DTO with validation
export class CreateOrderDto {
@IsString() @IsNotEmpty()
productId: string;

@IsNumber() @Min(1)
quantity: number;

@IsOptional() @IsString()
couponCode?: string;
}

// Enable globally in main.ts
app.useGlobalPipes(new ValidationPipe({
whitelist: true, // strips unknown fields
forbidNonWhitelisted: true, // throws on unknown fields
transform: true, // auto-transforms types
}));

HTTP & Routing Decorators

Decorator Source Description Example
@Param(key) Route param Extracts URL parameter @Param('id') — from /orders/:id
@Body() Request body Extracts request body (JSON) @Body() dto: CreateOrderDto
@Query(key) Query string Extracts query param @Query('page') — from ?page=2
@Headers(key) Request headers Extracts header value @Headers('authorization')
@Req() Raw request Entire Express/Fastify req object Avoid unless necessary
@Res() Raw response Full control over response Loses Interceptor/Pipe benefits
@HttpCode(n) Response Override default status code @HttpCode(204) for no content
@Redirect(url) Response Redirect to another URL @Redirect('/new-path', 301)
@Header(k, v) Response Set a response header @Header('Cache-Control', 'none')
07

Application Lifecycle Hooks

1

OnModuleInit

Called once the module's dependencies are resolved. Use for initialization tasks like connecting to external services or seeding data.

2

OnApplicationBootstrap

Called after ALL modules are initialized. The app is fully set up but not yet listening. Good for starting background tasks or schedulers.

▶

App is Running (listening for requests)

Normal operation. All lifecycle hooks below are part of graceful shutdown.

3

OnModuleDestroy

Called when a destroy signal is received. Use to clean up resources: close DB connections, cancel timers, flush queues.

4

BeforeApplicationShutdown

Called before the app shuts down. Receives the shutdown signal (e.g., SIGTERM). Can return a Promise to delay shutdown.

5

OnApplicationShutdown

Called after the HTTP server closes. Final cleanup. Enable shutdown hooks in main.ts: app.enableShutdownHooks().

08

Advanced Concepts

Execution Context

ExecutionContext

Available in Guards and Interceptors. Provides context about what's being executed — HTTP, WebSocket, RPC, etc. Use switchToHttp(), switchToWs(), etc.

Metadata

Reflector

Reads metadata set by decorators. Used in Guards to read custom decorator data. Example: read @Roles('admin') in an AuthGuard via reflector.get('roles', context).

CQRS

Command / Query / Event

Pattern for separating reads from writes. CommandBus dispatches commands. QueryBus fetches data. EventBus publishes domain events. From @nestjs/cqrs.

Config

ConfigModule / ConfigService

Loads environment variables safely. ConfigModule.forRoot() in AppModule. Inject ConfigService and use configService.get('DB_HOST'). Supports validation schemas.

Scheduling

@Cron / @Interval

Task scheduling via @nestjs/schedule. @Cron('0 * * * *') runs on schedule. @Interval(5000) runs every 5 seconds. @Timeout(n) runs once after delay.

Swagger

API Documentation

Auto-generates OpenAPI docs. Key decorators: @ApiProperty() on DTO fields, @ApiOperation() on endpoints, @ApiTags() on controllers, @ApiBearerAuth() for auth.

Microservices

MessagePattern / EventPattern

@MessagePattern('cmd') — handles request-response. @EventPattern('evt') — fire-and-forget. ClientProxy sends messages. Supports TCP, Redis, Kafka, NATS, etc.

WebSockets

Gateway

@WebSocketGateway() creates a socket server. @SubscribeMessage('event') handles messages. @WebSocketServer() injects the socket server instance.

Database

Repository Pattern

TypeORM: @InjectRepository(Order) injects the repo. Use repo.find(), repo.save(), repo.delete(). Entity classes decorated with @Entity(), @Column().
